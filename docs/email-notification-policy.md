# 이메일 알림 정책

> 상태: 기준
> 적용일: 2026-08-09
> 대상: Image Partners가 회원·사진작가·관리자에게 발송하는 거래·상태 알림

## 목적과 원칙

이메일은 사용자가 별도 행동을 해야 하거나 계정 권한·금전·업무 기회·반려 상태처럼 놓치면 손해가 생기는 사건에 한정한다. 사용자가 현재 화면에서 바로 확인한 성공 결과와 관리자 화면에서 상시 확인할 수 있는 일반 대기열 변화는 이메일로 반복하지 않는다.

- 가입 인증과 비밀번호 재설정은 계정 접근에 필요하므로 발송한다.
- 권한, 정산, 반려, 이미지 의뢰처럼 대응이 필요한 상태 변화는 발송한다.
- 이미지 업로드 완료는 업로드 화면과 사진작가 목록에서 확인하고 이메일을 발송하지 않는다.
- 이미지 승인은 사진작가 목록의 상태로 확인하고 이메일을 발송하지 않는다.
- 신규 업로드는 관리자 이미지 심사 대기열에서 확인하며 운영 수신함에 건별·묶음 메일을 발송하지 않는다.
- 메일에는 비공개 이미지 URL, 원본 파일, API 키 또는 불필요한 개인정보를 포함하지 않는다.

## 사진작가 알림 기준

| 사건 | 수신자 | 채널 | 기준 |
| --- | --- | --- | --- |
| 이메일 가입 확인·비밀번호 재설정 | 회원 | 이메일 | Supabase Auth SMTP가 발송한다. |
| 사진작가 신청 승인 | 신청자 | 이메일+화면 | 최초 승인과 정지 후 재신청 승인 모두 사진작가 권한 활성화를 알린다. |
| 사진작가 신청 거절 | 신청자 | 이메일+화면 | 거절 사유와 재신청 경로를 알린다. |
| 사진작가 권한 정지 | 사진작가 | 이메일+화면 | 운영 사유와 재신청 경로를 알린다. 별도 즉시 해제 버튼은 없으며 재신청 승인으로 복구한다. |
| 이미지 의뢰 초대 | 대상 사진작가 | 이메일+화면 | 의뢰명, 지역·기한·예산 등 저장된 조건과 계정 확인 경로를 알린다. |
| 정산 지급 완료·처리 거절 | 사진작가 | 이메일+화면 | 기간, 금액과 필요한 경우 거절 사유를 알린다. |
| 이미지 반려 | 사진작가 | 이메일+화면 | 관리자 반려와 자동 반려 모두 사유와 재검토 경로를 알린다. |
| 이미지 업로드 완료 | 사진작가·운영팀 | 화면만 | 사진작가는 업로드 결과를, 운영팀은 관리자 심사 대기열을 확인한다. |
| 이미지 승인·공개 | 사진작가 | 화면만 | 사진작가 이미지 목록의 승인·공개 상태를 기준으로 한다. |

구매자의 주문 접수·입금 확인·취소와 문의 접수·처리 알림은 각 거래·고객지원 흐름의 기존 기준을 유지하며 이 정책 변경으로 제거하지 않는다.

## 실패 처리와 회귀 기준

- 이메일 장애가 이미지 승인·반려, 사진작가 심사, 권한 정지 또는 정산 상태 변경을 되돌리지 않는다. 실패는 서버 로그에 남기되 개인정보와 본문은 기록하지 않는다.
- 이미지 의뢰 초대는 전달 실패 시 초대 상태를 확정하지 않고 운영자가 다시 시도할 수 있게 오류를 반환한다.
- 회귀 테스트는 업로드 API·화면·이메일 모듈에 업로드 완료 발송 경로가 없고, 이미지 승인 발송 경로가 없으며, 신청 결정·권한 정지·정산·반려·의뢰 초대 발송 경로가 유지되는지 확인한다.

## 변경 기록

- 2026-08-09: 운영팀 신규 업로드 건별·묶음 메일과 사진작가 이미지 승인 메일을 제거했다. 행동 필요·권한·금전·반려·이미지 의뢰 중심의 정책을 기준으로 확정했다.
