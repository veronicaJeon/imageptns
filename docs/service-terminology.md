# Image Partners 서비스 표준 용어

이 문서는 구매자, 사진작가, 관리자 화면과 이메일·정책 문서에서 사용하는 한국어 기준 용어를 정의한다. 데이터베이스 상태값과 API 필드명은 호환성을 위해 영문 내부값을 유지한다.

| 개념 | 기준 용어 | 사용 원칙 |
| --- | --- | --- |
| 서비스 자산 | 이미지 | 파일이나 라이브러리 항목을 가리킬 때 `사진`, `작품`, `콘텐츠` 대신 사용한다. 촬영 행위 자체를 설명할 때만 `사진`을 쓸 수 있다. |
| 공급자 역할 | 사진작가 | `사진가`, `작가`, `포토그래퍼`를 역할명으로 사용하지 않는다. |
| 크레디트 | 사진작가명 또는 스튜디오명 | 짧은 표시는 `사진작가명`으로 쓴다. 법적 저작자 표시를 설명할 때는 `저작자 표시`를 쓸 수 있다. |
| 고객 역할 | 구매자 | `바이어`를 사용하지 않는다. |
| 이미지 의뢰 | 이미지 요청 | 보유 이미지 확인과 신규 촬영 가능성 확인을 모두 포함한다. |
| 이용 조건 | 라이선스 | `라이센스` 표기를 사용하지 않는다. |
| 유료 행동 | 사용권 구매 | 이미지나 저작권 자체를 양도받는 것으로 오해할 수 있는 단독 `이미지 구매` 표현을 피한다. |
| 무료 행동 | 무료 사용권 확정 | 결제가 없는 흐름에 `무료 구매`를 사용하지 않는다. |
| 결제 방식 | 계좌이체 | `계좌결제`, `오프라인 결제` 대신 사용한다. |
| 거래 기록 | 주문 | 생성된 거래 단위를 가리킨다. 결제 완료 후 상태 변경은 `주문 확정`으로 쓴다. |
| 이미지 검수 | 검토 대기 / 승인됨 / 반려됨 | 같은 이미지 상태에 `검토 중`, `거절됨`을 사용하지 않는다. |
| 사진작가 신청 | 승인 대기 / 승인됨 / 승인되지 않음 | 이미지 반려와 사람의 자격 심사 결과를 구분한다. |
| 노출 중단 | 공개 중지 | 데이터는 유지하되 검색·신규 주문에서 제외된 상태다. |
| 삭제 의사 | 삭제 요청 | 사진작가가 운영 검토를 요청한 상태다. |
| 데이터 제거 | 완전삭제 | 복구할 수 없는 파일·데이터 제거를 뜻한다. `영구삭제`와 혼용하지 않는다. |
| 온체인 기록 | Arweave 원본 증명 | 구매자·사진작가 화면의 기준 표현이다. 기술 세부 화면에서는 자격증명 필드명을 병기할 수 있다. |

## 문장 작성 기준

- 버튼은 결과가 드러나도록 `사용권 구매`, `무료 사용권 확정`, `계좌이체 요청`처럼 쓴다.
- `주문`, `결제`, `라이선스`, `다운로드 권한`을 구분한다. 주문은 기록, 결제는 금액 처리, 라이선스는 이용 조건, 다운로드 권한은 원본 접근 결과다.
- 삭제 안내에는 `공개 중지`, `삭제 요청`, `완전삭제` 중 실제 처리 수준을 명시한다.
- 관리자 화면에서도 구매자·사진작가 화면과 같은 상태명을 사용한다.
