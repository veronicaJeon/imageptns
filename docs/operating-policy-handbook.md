# 이미지파트너스 운영정책 문서함

이 문서는 관리자와 운영 에이전트가 계좌이체 주문의 취소·환불 및 결제증빙 요청을 처리할 때 참고하는 운영 안내다.
실제 적용 본문은 관리자 `운영정책관리 > 운영정책 문서함`에서 관리하며, 공시사항의 정책 초안과 같은 데이터 원본을 사용한다.

## 현재 운영 단계

- 현재 서비스는 제한된 베타 운영 단계다.
- 계좌이체 주문 흐름은 내부 검증을 위해 유지한다.
- 월 정액권 가격, 제공 범위, 해지·환불 기준은 아직 확정되지 않았다.
- 불특정 고객에게 정식으로 청약을 받기 전에 사업자 공시, 주문 고지·동의, 세무 운영기준을 재검토한다.

## 운영 판단 원칙

1. 입금 확인 전에는 주문자 본인과 주문번호를 확인한 뒤 취소할 수 있다.
2. 입금 후 원본 다운로드 권한 제공 전에는 입금 내역을 확인하고 전액 환급을 원칙으로 한다.
3. 원본 권한 제공 후 단순 변심 요청은 주문 당시의 청약철회 제한 고지와 동의 기록을 확인한 후 판단한다.
4. 파일 오류, 오제공 또는 중대한 권리 하자는 다운로드 여부와 무관하게 재제공·교환·환급을 우선 검토한다.
5. 증빙 발급은 주문과 입금 사실, 신청인 정보, 기존 발급 여부를 확인하고 중복 발급을 방지한다.
6. 정책만으로 판단하기 어려운 권리·세무·소비자 분쟁은 임의 종결하지 말고 관리자에게 에스컬레이션한다.

## 정식 공개 전 미확정 항목

- 월 정액권 가격과 포함 이미지 수
- 초과 사용, 중도 해지 및 환불 산식
- 부가가치세 포함 여부
- 현금영수증·세금계산서 실제 발급 절차
- 사업자 법정 표시사항 공개 시점
- 원본 제공 전 청약철회 제한 고지·동의 기록 방식
